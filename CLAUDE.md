# via-latina

Mobile-first vocabulary quiz for Latin. One Latin word per screen with four Czech meanings; after answering, the card shows the right meaning, the grammar info and (if present) an example sentence with translation and a remark. UI copy is Czech.

## Stack

- React 18 + Vite 6, TypeScript strict, ESLint flat config, Vitest for pure logic. Same setup as the sibling `latin-rosary` project (its `package-lock.json` was reused because a fresh `npm install` hit an npm arborist bug).
- Plain CSS in `src/index.css` with tokens on `:root` (`--bg`, `--fg`, `--font`); dark mode via `prefers-color-scheme` swaps black/white.
- Static site; `BASE_PATH` env var sets the Vite base. The user deploys the output of `npm run build:web` (base `/via-latina/`) to jaroslavtesarik.cz/via-latina/ on their own.
- PWA like `latin-rosary`: `public/manifest.webmanifest`, `public/icon.svg` (+ `icon-180/192/512.png` rendered from it with Inkscape; iOS needs the PNG apple-touch-icon), `public/sw.js` (cache name stamped per build by the `swVersion()` plugin in `vite.config.ts`; network-first for pages, cache-first for assets; `activate` deletes only old `vialatina-*` caches because other apps on jaroslavtesarik.cz share the same Cache Storage; lookups use `ignoreVary` because module scripts carry an Origin header). New builds wait for the user: `src/useServiceWorkerUpdate.ts` (copied from latin-rosary, plus it posts `CACHE_URLS` with everything the first visit loaded so the app is offline right away) + `src/components/UpdateToast.tsx`. The font is bundled via `@fontsource/atkinson-hyperlegible-next` (no Google Fonts) so it works offline.
- Repo: github.com/tesarik/via-latina (public), branch `main`.
- Live at https://jaroslavtesarik.cz/via-latina/ (WEDOS; the user uploads `dist/` by hand). The host's CDN caches HTML for ~5 min plus stale-while-revalidate, so a fresh deploy may show up one reload late; plain http:// is not redirected to https.

## Commands

`npm run dev` · `npm test` · `npm run typecheck` · `npm run lint` · `npm run build` · `npm run build:web` (for the website) · `npx vite preview --base /via-latina/` to try the production build incl. offline. Run typecheck, lint and test before committing.

## File map

- `src/lessons/` — vocabulary. Every file whose name starts with a digit is a lesson; `index.ts` loads them with `import.meta.glob` and the file name (without `.ts`) is the lesson id and sort order. `define.ts` has the `n`/`v`/`a`/`o` helpers (noun, verb, adjective, other) and `lesson(title, description, entries)` (the description is one line under the title in the lesson picker, saying what kind of words the set has, with a few Czech examples); an optional 4th argument `[ex, tr, remark?]` is the example shown after answering.
  - `00-zakladni-slovicka.ts` "Slovíčka 1" (311 words, all with examples and remarks).
  - `01-slovicka-2.ts`, `02-slovicka-3.ts` "Slovíčka 2/3" (~350 each, with examples and remarks). Transcribed from OCR, so grammar info (vowel lengths, principal parts) may contain errors; fix them when the user reports any.
  - `03-slovicka-4.ts` … `05-slovicka-6.ts` "Slovíčka 4–6" (300/300/281): everyday Roman-life vocabulary from a textbook's word index (the user owns the book), only words not in the other sets, most useful first (many references / early chapter). Written by AI; examples are real quotes or own sentences, never sentences from that book (copyright). The book is not named in the repo (as with sets 2/3) unless the user asks; same caveat about grammar errors.
  - `06-slovicka-7.ts` "Slovíčka 7" (274 liturgical words not in sets 1–3, most frequent first, with examples). Lemmatised from Latin text, same caveat about possible grammar errors.
  - `07-slovicka-8.ts` "Slovíčka 8" (300) and `08-slovicka-9.ts` "Slovíčka 9" (108): words from prayers, hymns, psalms and catechism lists not in sets 1–3 and 7; set 8 has the more common ones, set 9 the rarer. Lemmatised and written by AI (incl. examples), same caveat.
  - Order (user's wish): basic 1–3, then Roman life 4–6, then liturgical 7–9. Lesson ids are file names, so after renumbering a saved selection points to whatever set now has that file name; progress is keyed by word, not lesson, so it survives.
- `src/quiz/engine.ts` — pure logic: `poolFor` (words of selected lessons, deduped by la+cz), `drawNext` (shuffled passes with `pass`/`size` counted in `DeckState`, every word once per pass but never opening with the word that closed the last one; missed words return after `RETRY_GAP`), `pickOptions` (distractors of the same word class, preferring the selected lessons, never two options with the same Latin or Czech).
- `src/quiz/progress.ts` — per-word Leitner box with review days across visits (`vialatina_progress` in `localStorage`, key `pos:la:cz`; `due` is a local day number from `today()`, missing in old data = due). Wrong → box 0, due today; right → +1 box (max 4) and due in `INTERVAL_DAYS[box]` (1/3/7/21 days) **only when the word was due**, otherwise the box stays, so known (box ≥ 3) takes three right answers on different days. `isDue` = seen and due; `isMissed` = ever wrong and box < 3; `isWeak` = missed and due (a weak word answered right waits for its next review). `weightOf` feeds `drawNext`, which orders each pass with `weightedOrder`: due low boxes first, unseen middle, not-yet-due last (every word is still asked once per pass). `totals()` sums all answers ever for the header. `skip` ("Umím, už se neptej", `setSkip`) makes a word known and never due; taking it back from a word never answered deletes the record so it is new again. `exportProgress`/`importProgress` make and read the backup file (`{app:"via-latina", version, date, progress}`; a bare progress map is accepted too); the settings sheet saves it via the Web Share API when files can be shared, else a download, and restoring replaces the whole progress.
- `src/quiz/session.ts` — round state (incl. `progress` and `focus`: `"weak"` asks only `isWeak` words, `"due"` only `isDue` words, both with distractors from the whole selection, and switch to `"all"` with a fresh pass once none are left; `"grammar"` asks grammar questions, see grammar.ts, with `Question.grammar` holding the choices and `options` empty) and `answer()`; keeps at most `HISTORY_LIMIT` (20) cards. Each `Question` carries `pass`/`n`/`of`, shown on the card as "kolo 2 · 145 / 311". `saveRound`/`restoreSession` keep the round between visits (`vialatina_round`: deck and retries by word key plus the open card); App restores it on launch when the lesson selection still matches. Rounds ask only words not marked `skip` (unless every word of the selection is); `skipWord` also drops the word from the rest of the pass and shrinks its size.
- `src/quiz/settings.ts` — selected lesson ids in `localStorage` (`vialatina_settings`; empty = all) plus `toggleLesson`/`lessonsFor`: the settings sheet keeps its own explicit ticked list, which may be empty for a moment ("Všechny lekce" unticks everything so one lesson can be picked); the round changes only while at least one lesson is ticked, and ticking all collapses to "all".
- `src/quiz/grammar.ts` — grammar questions read from `info`: noun gender + declension (from "corporis n."; 5th only for -ēs nouns with -eī, 4th only with a macron -ūs) and verb conjugation (from the infinitive; a plain -ere counts as 3rd only when the entry has macrons elsewhere). Left out on purpose: plurals only, "m./f.", irregular verbs and compounds (esse, ferre, īre/-eo, velle/nolle/malle, fierī). `grammarKey(kind, w)` = `kind|pos:la:cz`, a separate progress record so "umím" stays about meanings. Session focus `"grammar"` (start screen "Gramatika: rod, 2. pád, konjugace") asks one kind per word per pass, the one with the highest weight; the card hides `info` until answered and shows the Czech meaning instead; the wrong-answer label is "la = right choice".
- `src/quiz/types.ts` — `Word`, `Lesson`, `Note`, `Settings`.
- `src/App.tsx` — the snap-scrolling feed. Remembers which card is on screen and restores it when old cards are dropped (`overflow-anchor: none`, feed is `position: relative` so `offsetTop` is feed-relative). Keyboard: 1–n (`choiceCount`: 4 meanings, 3 genders, 5 declensions, 4 conjugations) answer the open card if it is on screen, Enter/↓ go to it.
- `src/components/StartScreen.tsx` — shown on every launch as a fixed overlay over the feed (the feed stays mounted, so returning keeps the place): known x / y and seen ("Prošel jsi") x / y for the selection, one bar with seen hatched and known solid, the place in the round, "Dnes k zopakování: n", a backup reminder when there was none for `BACKUP_REMIND_DAYS` (7), "Začít" (no progress yet) / "Pokračovat", "Zopakovat dnešní (n)" and "Opakovat chybná slovíčka (n)" when some exist, "Gramatika: rod, 2. pád, konjugace", "Vybrat lekce" (opens the settings sheet), "Seznam slovíček". Tapping "Via Latina" in the header goes back to it.
- `src/components/QuestionCard.tsx` (card, ↑ previous / ↓ next buttons, "Nahlásit chybu" and, on meaning cards, "Umím, už se neptej" / "Vrátit" at the end of the note), `SettingsSheet.tsx` (bottom sheet with lesson checkboxes, each lesson's description and "umím x / prošel y / z"; rows are `flex: none` so the scrolling list never squeezes them), `WordList.tsx` (full-screen list of a lesson / the selection / everything, accent-insensitive search in Latin or Czech, filter by state incl. "Neptat se", tap a row for the example and "Umím, už se neptej" / "Zase se ptát"), `StatTip.tsx` (tap-to-explain bubble for the header figures).
- `src/report.ts` — error report text for a word, handed to the share sheet or copied. `src/backup.ts` — `saveBackup` (share sheet or download) and the day of the last backup (`vialatina_backup`).
- `src/quiz/engine.test.ts` — all tests (engine, session incl. saved round, progress and review days, grammar parsing and the grammar round), including lesson-data checks (no empty fields, no duplicate pos+headword within a lesson, every word has an example sentence with translation).

## Adding vocabulary from a Latin text (how sets 4–9 were made)

1. `pdftotext -layout` the PDF; keep only Latin lines (drop lines with Czech háčky/ů/ý or Czech function words); join words split by hyphen/line break (chant notation splits syllables: "Ie-su").
2. Count normalised forms (lowercase, no accents, æ→ae, j→i), lemmatise them (subagents, form → lemma + pos; mark proper names and non-Latin junk), sum counts per lemma.
3. Drop lemmas already in any set (compare normalised headwords), proper names, fragments and very specialised terms.
4. Write entries (info with macrons, Czech meaning with verbs in 1st person, example sentence preferably a real quote with reference, short remark) in parallel subagents to JSONL, then validate (duplicates vs existing `pos:la`, verbs not in infinitive) and generate the lesson file. Order: most useful/frequent first; split into sets of ~300.
5. `npm test`, update README "Slovní zásoba" and this file, commit and push.

## Decisions from the user (keep them)

- Calm pace: **no automatic advance**; after every answer the learner moves on with the ↓ button or by swiping. ↑ goes back with the same smooth scroll.
- Czech meanings of **verbs are in the 1st person sg. in every set** ("miluji", "přijímám"), never the infinitive, so the form never gives the answer away.
- Direction is **Latin → Czech only** (Czech → Latin was removed on request).
- Look: **black and white**, sans-serif (Atkinson Hyperlegible Next), large type. State is shown by fill/dashed border/strike-through; the only colour is the verdict label ("Recte!" green, wrong-answer label red, `--good`/`--bad`), added on request.
- After answering, the options not involved disappear (correct → only the right one; wrong → right + picked), so the example has room. Option buttons are compact (min-height 48px, user asked for less height). Once the example shows, the card gets `.has-note` and the headword steps down in size; the wrong-answer label is just "la = cz" (grammar info is already on the card). Checked at 375×667: every example fits after a right answer, a handful of the longest scroll after a wrong one. `.prompt` has `overscroll-behavior: contain` so scrolling a long example doesn't flip to the next card.
- Lessons are **vocabulary sets of roughly 300 words**, not textbook grammar chapters; titles are just "Slovíčka N". A new set leaves out words already in earlier sets.
- **Every word has an example sentence** with Czech translation (enforced by a test); remarks are optional. Examples/notes are AI-written; the user reports errors and they get fixed.
- **Do not mention the source** of Slovíčka 2/3 anywhere in the repo (README, comments, docs).
- **No pronunciation / text-to-speech**: speaker buttons (Italian voice) were tried and removed on request.
- "Nahlásit chybu" only shares or copies the text; no e-mail address goes into the (public) repo.
- Header: "správně x/y" counts all answers ever (summed from the stored per-word `seen`/`wrong`, `totals()`), "série" only since launch; both explain themselves via tap tooltips; keep the streak tooltip short.
- Commit and push to `main` after each finished change; end commit messages with the Co-Authored-By line.
- Work only in this repo; don't change or open PRs in sibling projects (latin-rosary…) from a via-latina session.
